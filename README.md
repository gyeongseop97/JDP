# 수상한 전당포 · Midnight Pawn v5.0

자정의 전당포에서 손님의 말, 물건의 흔적과 가격을 비교하는 모바일 싱글 플레이 게임입니다. 시간 제한은 없습니다.

## 이번 버전: 근거를 읽는 감정

1. 손님에게 표식·세공·보존에 관한 구체적인 질문을 합니다. 물건 분류마다 질문과 부위가 다릅니다.
2. 돋보기는 작은 선과 표면, 불빛은 색·반사·투과를 확인합니다. 도구를 고르고 살필 부위를 누릅니다.
3. 감정 수첩의 제작 관례와 손님의 말, 직접 본 흔적을 비교합니다. 진품/가품 정답이나 추천 도구를 자동 표시하지 않습니다.
4. 어떤 설명이 틀렸는지 직접 선택해 반박하거나, 발견한 좋은 세공을 숨기거나 알려주고 가격을 제안합니다.
5. 매입 뒤에는 진위·세공·보존을 나눈 감정 풀이로 판단을 돌아봅니다.

질문과 조사는 무료이며 횟수 제한이 없습니다. 과한 가격 제안, 근거 없는 반박과 단정은 호감도와 협상 여유를 줄입니다. 같은 조사를 반복해도 새로운 단서나 호감도를 얻지 않습니다.

같은 이름의 물건에도 진품과 모조품이 있습니다. 진위·제작 솜씨·보존 상태는 서로 다른 축입니다. 세공 관측은 세 단계의 특징을 보여 주며, 거래 전 정확한 9등급과 가격까지 알려주지는 않습니다. 일부 희미한 진위 흔적은 감정 도구를 강화한 뒤 다시 조사해야 더 읽을 수 있습니다. 원래 판단한 흔적은 화면 갱신으로 다시 무작위 결정되지 않습니다.

## 손님과 거래

144가지 물건, 24명의 손님, 9개 등급, 무작위 사건이 있습니다. 판매하러 온 손님뿐 아니라 구매 손님도 찾아옵니다. 금액을 직접 입력해 흥정하며 합의 뒤 매입/판매 버튼으로 확정합니다. 친밀도와 취향은 흥정에 영향을 줍니다. 구매 손님의 물건별 사연 소개와 보증은 서로 구분되고, 물건을 돌려 보여 주어 호감도를 반복 획득할 수 없습니다.

24명에게 상황별 완결 대사를 적용했습니다. 이전의 뜬금없는 관심사 선택지는 거래 우선순위 질문으로 바꾸었습니다.

## 시작 화면과 저장

- 새로 시작: 새 가게. 기존 저장을 교체하기 전에 확인합니다.
- 불러오기: 같은 주소·기기·브라우저의 가게를 이어갑니다.
- 체험 튜토리얼: 별도 연습 가게에서 27단계를 직접 진행합니다. 실제 저장을 바꾸지 않습니다.

v3/v4 저장을 읽어 v5로 이어갑니다. 금고·재고·관계·현재 거래 금액은 유지합니다. 진행 중인 손님의 감정 기록은 새 규칙으로 시작하며 v4 대화 기록은 전체 대화 안의 이전 버전 기록에 보관합니다.
