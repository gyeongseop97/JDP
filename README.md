# 수상한 전당포 · Midnight Pawn

144종의 물건과 24명의 손님이 찾아오는 모바일 도트 전당포 게임입니다. 타이밍이나 반사 신경 대신 단서, 흥정, 위험 판단으로 거래합니다.

## 휴대폰에서 시작하기

이 폴더를 GitHub 저장소에 올리고 Pages를 켜면, 휴대폰 브라우저에서 바로 플레이할 수 있습니다. 별도 빌드, 패키지 설치, API 키는 필요하지 않습니다.

- 업로드할 저장소: [gyeongseop97/JDP](https://github.com/gyeongseop97/JDP)
- 게시 설정을 마친 뒤 사용할 예상 주소: [수상한 전당포](https://gyeongseop97.github.io/JDP/)
- 처음 올린다면 [GitHub 업로드 안내](GITHUB-PAGES.md)를 순서대로 따라 하세요.

ZIP 파일을 그대로 올리지 마세요. 압축을 푼 **폴더 안의 파일들과 `assets` 폴더**를 저장소 최상위에 올려, 저장소를 열자마자 `index.html`이 보이게 해야 합니다. 위 주소는 게시 완료를 확인한 주소가 아닙니다.

## 플레이

1. 손님이 가져온 물건을 돋보기, 청광등, 사연 듣기로 조사합니다. 사용한 도구를 다시 누르면 이전 단서를 읽습니다.
2. 감정가는 어디까지나 추정입니다. 진품도 의심스러울 수 있고, 정교한 가품은 모든 검사를 통과할 수 있습니다.
3. 두 번까지 흥정하거나 요청가에 매입합니다. 매입 뒤 실제 등급, 진위와 가치가 공개됩니다.
4. 즉시 판매하거나 진열하세요. 진열 판매는 손님 두 명이 다녀간 뒤 확정됩니다.
5. 하루 여덟 손님을 만나면 마감합니다. 새 사건과 시세, 수집 의뢰가 다음 밤에 찾아옵니다.

## 콘텐츠

- 12개 품목 분류, 고유한 이름·단서·유래·특성을 가진 아이템 144종
- 낡음·평범·양질·희귀·진귀·유물·전설·신화·금기의 9등급
- 별도 도트 원화와 첫 방문·재방문·흥정 대사를 가진 손님 24명
- 시세·선물·의뢰·소문 사건 24개와 첫 거래에 연결된 후속 이야기
- 큰 손실이 나는 정교한 위조품, 평범해 보이는 숨은 보물
- 보관함·진열 판매·수집록·가게 강화 15단계·업적 8개·거래 장부
- 소지금이 부족하고 재고가 없을 때 하루 한 번 심부름으로 200G 회복

## 저장과 홈 화면

같은 기기와 브라우저에 자동 저장됩니다. 거래·감정·진열·사건 상태가 함께 저장되고, 손상된 주 저장은 백업을 확인합니다. 다른 기기나 브라우저와 자동 동기화되지 않으며, 브라우저 데이터를 지우면 진행도 사라집니다.

휴대폰 브라우저 메뉴에서 **홈 화면에 추가**를 선택하면 아이콘으로 실행할 수 있습니다. 홈 화면 추가를 지원하지만 **오프라인 플레이는 지원하지 않습니다.** 효과음은 기본적으로 꺼져 있으며 게임 설정에서 켤 수 있습니다.

## PC에서 미리 보기

`index.html`을 브라우저로 열거나 이 폴더를 정적 웹 서버로 제공할 수 있습니다. Node.js가 설치되어 있다면 이 폴더에서 다음 명령으로 GitHub Pages와 같은 경로를 미리 확인하세요.

```text
node preview.cjs --base /JDP/ --port 4175
```

실행 후 [PC 미리 보기](http://127.0.0.1:4175/JDP/)에 접속합니다. 이 주소는 실행한 PC에서 사용하는 주소이며, 휴대폰에는 위 GitHub Pages 주소를 사용하세요. 게임은 외부 서비스나 AI API를 호출하지 않습니다.

## 검증

`node verify.cjs`로 콘텐츠 수량, 거래 중복 방지, 진열 판매, 사건 보상, 손상된 저장, 복구 경로 및 2,000회 거래 시뮬레이션을 확인할 수 있습니다. 브라우저에서 모바일 크기, 모든 메뉴, 실제 매입·판매, 저장 복원을 검증했습니다.

## 파일

- `index.html`, `style.css`: 반응형 게임 화면
- `engine.js`: 거래, 감정, 확률과 성장 규칙
- `app.js`, `panels.js`: 화면과 조작
- `items.js`, `characters.js`: 콘텐츠 데이터
- `sprites.js`: 아이템 도트 렌더링
- `assets/`: 상점 배경·캐릭터 원화(WebP), 홈 화면 아이콘
- `GITHUB-PAGES.md`: GitHub 업로드 및 게시 안내

배경 한 장과 캐릭터 시트 세 장은 이 게임용으로 생성했습니다. 자세한 제작 기록은 `ARTWORK.md`에 있습니다.
