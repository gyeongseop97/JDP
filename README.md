# 수상한 전당포 · Midnight Pawn v6.10

손님의 말과 물건의 흔적을 읽고 내 가격을 정하는 모바일 싱글 플레이 게임입니다.

## 시작과 업로드

ZIP 안의 파일 전체를 기존 index.html과 같은 위치에 덮어쓰세요. 이미지 17개와 Galmuri11.woff2가 함께 있어야 합니다. 새 스크립트와 스타일도 빠뜨리지 마세요. 이미지 파일을 별도 폴더로 옮기지 않습니다. GitHub Pages의 /JDP/ 같은 하위 경로도 지원합니다.

시작 화면: 새로 시작 / 불러오기 / 체험 튜토리얼. 40단계 튜토리얼은 실제 기능을 조작하며 배우고 원하는 장부터 연습할 수 있습니다. 연습은 실제 저장을 바꾸지 않습니다.

질문은 인물 아래 대화창에만 있습니다. 외관·기능·특징·진위에 관해 물으면 한 번에 단서 하나를 듣습니다. 질문 기회가 남으면 같은 질문을 다시 할 수 있으며, 직접 조사해 듣지 못한 단서를 찾을 수도 있습니다. 어디서 언제 구했는지와 사연도 물어볼 수 있습니다. 모바일 하단에서는 조사·기록(물건 고르기)이나 가격 제안을 엽니다.

## 감정과 거래

144종 각각 진품과 가품이 존재합니다. 진위·제작 수준·보존 상태는 별개여서 정교한 가품, 손상된 진품도 있습니다. 손님의 정직성·확신·물건의 실제 진위 역시 다릅니다.

질문에서 궁금한 곳을 찾고 도구와 부위를 골라 수첩과 비교하세요. 모순이나 정답을 자동 표시하지 않습니다. 조사 없이 거래해도 됩니다. 출처의 구매 연도·제작 사연을 도록과 비교할 수도 있습니다. 출처가 틀렸다고 물건까지 무조건 가품은 아닙니다. 연대와 사연은 게임의 가상 설정입니다.

- 가격 제안: 기본 2회. 호감도 −25 이하 1회 / 25~59는 3회 / 60 이상은 4회. 보통 제안은 1회, 모욕적인 제안은 2회를 쓰거나 거래가 끝납니다. 합의 후에도 기회가 남으면 추가 흥정을 선택할 수 있습니다.
- 질문: 호감도 −25 이하 1회 / −24~24는 2회 / 25~59는 3회 / 60 이상은 4회.
- 조사: 기본 2회. 작업대 강화로 3·4·5·6회가 됩니다. 비용은 1,500 / 4,500 / 11,000 / 24,000G입니다.
- 작업대 1·2·3단계에서 안쪽 교차 확인·제작자 서명·수리 또는 배합층 정밀 관찰이 차례로 열립니다. 기본 흔적을 먼저 봐야 합니다.
- 안목은 흐릿한 흔적을 읽는 능력입니다. 서명의 세부 획은 안목 2단계부터 읽습니다. 공방 서명표는 제작 수준의 근거이지 진품 보증은 아닙니다.
- 같은 기록 다시 보기는 무료. 안목 강화 후 내용이 더 자세해지는 재판독만 조사 1회를 씁니다.
- 근거를 가격 인하에 쓰거나 장점을 공개할 수 있습니다. 숨은 가치를 알려주면 신뢰와 함께 요구가가 오를 수도 있습니다. 매입 뒤 감정 풀이를 읽을 수 있습니다.

같은 이름의 물건에도 겉층을 손봤거나 재료를 다시 맞춘 경우가 있습니다. 물약은 배합층, 종이는 섬유, 직물은 올, 다른 재료는 표면과 접합을 확인합니다. 흔적을 해석하는 텍스트 퍼즐이며 이미지를 회전하거나 직접 긁어내는 미니게임은 아닙니다.

26명 손님은 말투·취향·정직성·물품 공급 성향이 다릅니다. 손님 정보에는 직접 확인한 거래 이력이 쌓입니다. 처음부터 숨겨진 확률을 공개하지 않습니다. 만족스러운 거래는 관계를 높이고 지나친 흥정이나 근거 없는 단정은 관계를 해칩니다.

구매 손님은 목적과 필수 상태를 갖고 옵니다. 선호품을 보관하고 있을 때 주로 사러 오며 찾던 물건과 선호품에는 높은 값을 생각합니다. 무관하거나 조건에 미달하는 물건은 거절합니다. 판매할 때는 조건·현재 물건의 예산·거래 성향을 묻고 들은 내용을 물건 선택 화면에서 확인할 수 있습니다. 판매 손님은 전문 분야의 물건에 근거 없는 흥정을 덜 받아들입니다. 사연 / 상태와 쓰임새 / 진품 보증 중 **방문당 한 가지 소개**를 고르며 협상 여유 1회를 씁니다. 상대에게 맞는 설명이 가격과 관계를 높입니다. 재고를 바꿔도 소개 기회가 돌아오지 않습니다. 가품임을 솔직히 알리는 선택은 별도로 할 수 있습니다.

## 거래의 후일담

일부 거래는 여러 손님이 지난 뒤 무작위 재방문으로 이어집니다. 가품을 알아본 구매자, 싼값에 넘긴 고가품의 진가를 들은 판매자, 자기 착각을 사과하는 손님, 답례하러 온 단골을 만납니다.

보상·대화·거절 중 선택하며 결과는 관계와 장부, 손님 정보에 남습니다. 돈을 자동으로 차감하지 않습니다. 답례금 대신 다음 좋은 물건을 먼저 보여 달라고 부탁할 수 있고, 이후 방문에서 약속을 지킵니다. 매입 여부는 그때 다시 고릅니다.

## 가게의 세 가지 즐거움

돈·수집·단골 목표는 동시에 쌓이고 관심 목표만 바꿀 수 있습니다. 단골 최종 목표는 26명입니다. 9등급, 24개 무작위 골목 사건, 구매·판매 손님, 도매·위탁·납품, 강화와 업적을 포함합니다.

손님 8명 뒤에는 밤의 자유 시간 2칸이 생깁니다.

- 도록 등록: 새 진품을 기록합니다. 물건은 소비되지 않으며 나중에 팔아도 기록이 남습니다.
- 차 한 잔: 25G로 호감도 +6. 한 손님은 한 밤에 한 번입니다. 호감도 25에서 개인 이야기가 열립니다.
- 재고 손질: 상태를 한 단계 개선합니다. 비용은 원가에 포함되며 가품은 진품으로 바뀌지 않습니다.

6개 테마의 물건 4종을 모두 등록하면 짧은 이야기와 120G를 한 번 받습니다.
정산 지원은 현금+재고 도매가 합계가 650G 미만일 때 최대 50G, 활동 보너스는 거래당 12G·야간 활동당 8G로 하루 합계 최대 120G입니다. 둘째 날부터 감사 선물은 거래나 야간 활동을 해야 받습니다. 무거래로 날짜만 넘겨 강화 자금을 쌓을 수 없습니다.
재고가 없고 소지금이 120G 미만이면 하루 한 번 심부름으로 200G를 받을 수 있습니다. 빚이나 실시간 접속 압박은 없습니다.
