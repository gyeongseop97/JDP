# 수상한 전당포 · Midnight Pawn v6.3

모바일에서 손님의 말과 물건의 흔적을 읽고, 내 가격을 정하는 싱글 플레이 전당포 게임입니다. 시간 제한 없이 진행합니다. 서버·가입·API 키 없이 GitHub Pages에서 실행됩니다.

## 새 손님 레온과 세린

왕실 경매사 레온과 자정 극장의 가수 세린이 추가되어 손님이 26명이 되었습니다. 기존 게임에 맞춘 도트 원화, 개별 말투·취향·거래 성향·단골 이야기를 갖고 있습니다. 판매와 구매 손님으로 무작위 방문하며, 마감 후 차 한 잔도 함께할 수 있습니다.

## 인사부터 시작하는 손님

26명 모두 인사와 물건 이름, 판매·구매 목적을 먼저 말합니다. 물건의 특징과 출처는 질문했을 때 들을 수 있습니다. 모카의 냥 말투, 월하의 어른 말투, 톱니의 사무적인 말투가 물품 설명·흥정·차 마시는 대화까지 이어집니다.

## 간단해진 매입

대화 → 궁금한 곳 조사 → 흥정 또는 매입으로 진행합니다. 진위·제작·상태를 일일이 고르던 판단 버튼과 그에 따른 예상 손익 계산을 없앴습니다. 조사 없이 바로 거래해도 됩니다.

- 질문 2회·조사 2회 안에서 궁금한 것만 고릅니다. 기록 다시 보기는 무료입니다.
- 손님 말과 물건을 비교하고, 확인한 흠을 가격 인하에 쓰거나 좋은 점을 알려 신뢰를 얻습니다.
- 참고 가격은 보통 진품의 도매가입니다. 현재 물건의 숨겨진 가격이나 정답이 아닙니다.
- 자세한 수첩·비교 기록·매입 뒤 풀이는 필요할 때 펼칩니다.
- 물품 144종의 질문과 진품·가품 문장, 15가지 재질의 마감·상태 표현을 짧은 한국어로 고쳤습니다.

## 말에서 찾는 단서

“언제 구하셨어요? 어떤 사연이 있나요?”를 물으면 구매 연도와 전해 들은 제작 사연을 듣습니다. 질문 횟수는 기존 한도에서 1회를 씁니다.

감정 수첩에는 처음 만든 해와 원래 사연이 있습니다. 제품이 나오기 전에 샀다고 하거나 제작 목적을 다르게 설명할 수 있습니다. 예를 들어 돌아오는 잉크는 잘못 쓴 계약서를 회수하려고 만든 물건인데, 손님은 글씨를 오래 남기려고 만든 물건이라고 말하기도 합니다.

출처 이야기를 펼쳐 **구매 시기**와 **제작 사연** 중 틀린 부분을 직접 지적합니다. 모순을 자동 표시하거나 정답 버튼만 활성화하지 않습니다. 맞게 지적하면 출처 설명의 신빙성이 흔들리고 요구가가 내려갑니다. 틀린 지적은 관계와 협상 여유를 해칩니다. 한 거래에서 한 번만 따질 수 있습니다.

출처가 틀렸다고 물건까지 무조건 가품은 아닙니다. 잘못 전해 들은 진품도 있고, 사연이 맞는 가품도 있습니다. 도록의 연도와 사연은 이 게임의 가상 설정이며 실제 역사 자료를 뜻하지 않습니다.

## 손님마다 다른 물건과 말

가품을 구해 오는 확률, 희귀품을 가져올 확률, 정직성을 별도로 적용했습니다. 정직하지만 가품을 자주 사 오는 손님과, 좋은 물건을 구하면서도 말을 부풀리는 손님이 모두 가능합니다. 어느 손님도 특정 결과를 보장하지 않습니다.

손님 정보에는 **직접 매입한 진품·가품 수, 희귀 이상 진품 수, 직접 짚은 출처 모순 횟수**가 쌓입니다. 처음부터 숨겨진 확률이나 사기꾼 표시를 공개하지 않습니다. 새 이력은 이번 업데이트 이후 확인한 거래부터 쌓입니다.

## 세 가지 즐길 거리

가게 관리에서 관심 목표를 언제든 선택합니다. 세 가지 기록은 동시에 쌓이며 관심 목표를 바꿔도 초기화되지 않습니다.

- **돈**: 누적 거래 이익 500 → 3,000 → 10,000 → 30,000G.
- **수집**: 밤에 진품을 도록에 등록하여 4 → 12 → 36 → 72 → 144종을 모읍니다. 6개 테마의 4종 세트를 완성하면 짧은 이야기와 120G를 한 번 받습니다.
- **단골**: 호감도 25 이상인 손님 1 → 3 → 8 → 16 → 26명을 만듭니다. 25에 도달하면 개인 이야기가 열리고, 우호적인 관계는 흥정에도 도움이 됩니다.

## 영업이 끝난 뒤

하루 여덟 손님을 맞이하면 자유 시간 **2칸**이 생깁니다. 아래에서 원하는 활동을 고릅니다. 남은 시간을 쉬어도 불이익이 없습니다.

- **도록 등록**: 보관한 새 진품 하나를 무료로 기록합니다. 물건이 소비되지 않으며 나중에 팔아도 기록이 남습니다. 등록 전에 팔면 그 물건을 다시 구해야 합니다.
- **차 한 잔**: 만난 손님에게 25G로 차를 대접하고 호감도 +6. 같은 손님은 한 밤에 한 번입니다.
- **재고 손질**: 보존 상태를 한 단계 높입니다. 손질비와 예상 도매가 상승을 비교하세요. 비용은 물건 원가에 포함되어 실제 이익에서 빠집니다. 같은 물건은 한 밤에 한 번이며 가품은 진품으로 바뀌지 않습니다.

위탁 중인 물건은 도록 등록/손질 대상이 아닙니다. 다음 영업으로 넘어가면 마감 보너스를 받고 새로운 손님·사건을 만납니다.

## 콘텐츠와 시작 화면

144종 물건, 26명 손님, 9등급, 24개 무작위 사건, 판매·구매 손님, 개별 성향과 취향, 거래 만족도와 관계, 도매·위탁·의뢰, 가게 강화, 도트 이미지와 한국어 픽셀 글꼴을 포함합니다.

144종 각각 진품·복제품 특징과 조사 부위를 작성했습니다. 제작·보존은 15가지 재질 규칙에 물품별 부위를 연결했습니다. 관찰은 텍스트 퍼즐이며 각 물품을 회전시키는 조작 미니게임은 아닙니다.

- 새로 시작: 기존 저장이 있으면 확인한 뒤 새 가게를 시작합니다.
- 불러오기: 같은 웹 주소·기기·브라우저의 저장을 이어갑니다.
- 체험 튜토리얼: 31단계를 직접 플레이합니다. 원하는 장면을 선택해 연습할 수 있고 실제 저장을 바꾸지 않습니다.
