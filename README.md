# 수상한 전당포 · Midnight Pawn v6.0

모바일에서 손님의 말과 물건의 흔적을 읽고, 내 가격을 정하는 싱글 플레이 전당포 게임입니다. 시간 제한 없이 진행합니다. 서버·가입·API 키 없이 GitHub Pages에서 실행됩니다.

## 이번 버전의 플레이

1. 질문 2회, 조사 2회 안에서 중요한 특징을 고릅니다. 첫 주장은 입장 대화로 주어집니다.
2. 말에서 부위와 도구를 유추하고 직접 살펴봅니다. 돋보기는 작은 선·홈, 불빛은 반사·색·투과를 확인합니다.
3. 감정 수첩과 관찰 결과를 비교하여 진위·제작·보존에 대한 **내 판단**을 기록합니다. 그 가정에 따른 예상 도매가와 손익이 바뀝니다. 계산기는 숨겨진 정답을 읽지 않습니다.
4. 흠을 협상 근거로 제시하면 요구가와 최저 수락가가 실제로 내려갑니다. 잘못된 주장은 호감도와 협상 여유를 잃습니다.
5. 숨은 좋은 세공은 혼자 알고 매입할 수도, 손님에게 공개하여 신뢰를 얻을 수도 있습니다. 공개하면 손님도 가치를 알아 요구가를 올립니다.
6. 원하는 금액을 직접 입력하여 흥정하고 확정합니다. 비싸면 거절하는 것도 좋은 선택입니다.
7. 매입 뒤 실제 가치와 감정 풀이를 보고 도매·위탁·구매 손님 거래 중 판매 방식을 고릅니다.

질문/조사는 금화 대신 기회를 소비합니다. 같은 관찰 기록의 다시 보기는 무료입니다. 도구 강화로 결과가 더 선명해져 재조사하는 경우는 기회를 씁니다. 감정 도구 3단계부터 **다음 방문**의 조사 기회가 3회가 됩니다. 잘못된 부위/도구도 1회를 씁니다. 평범한 질문과 조사에는 협상 인내심을 추가로 차감하지 않습니다.

## 세 가지 즐길 거리

가게 관리에서 관심 목표를 언제든 선택합니다. 세 가지 기록은 동시에 쌓이며 관심 목표를 바꿔도 초기화되지 않습니다.

- **돈**: 누적 거래 이익 500 → 3,000 → 10,000 → 30,000G.
- **수집**: 밤에 진품을 도록에 등록하여 4 → 12 → 36 → 72 → 144종을 모읍니다. 6개 테마의 4종 세트를 완성하면 짧은 이야기와 120G를 한 번 받습니다.
- **단골**: 호감도 25 이상인 손님 1 → 3 → 8 → 16 → 24명을 만듭니다. 25에 도달하면 개인 이야기가 열리고, 우호적인 관계는 흥정에도 도움이 됩니다.

## 영업이 끝난 뒤

하루 여덟 손님을 맞이하면 자유 시간 **2칸**이 생깁니다. 아래에서 원하는 활동을 고릅니다. 남은 시간을 쉬어도 불이익이 없습니다.

- **도록 등록**: 보관한 새 진품 하나를 무료로 기록합니다. 물건이 소비되지 않으며 나중에 팔아도 기록이 남습니다. 등록 전에 팔면 그 물건을 다시 구해야 합니다.
- **차 한 잔**: 만난 손님에게 25G로 차를 대접하고 호감도 +6. 같은 손님은 한 밤에 한 번입니다.
- **재고 손질**: 보존 상태를 한 단계 높입니다. 손질비와 예상 도매가 상승을 비교하세요. 비용은 물건 원가에 포함되어 실제 이익에서 빠집니다. 같은 물건은 한 밤에 한 번이며 가품은 진품으로 바뀌지 않습니다.

위탁 중인 물건은 도록 등록/손질 대상이 아닙니다. 다음 영업으로 넘어가면 마감 보너스를 받고 새로운 손님·사건을 만납니다.

## 콘텐츠와 시작 화면

144종 물건, 24명 손님, 9등급, 24개 무작위 사건, 판매·구매 손님, 개별 성향과 취향, 거래 만족도와 관계, 도매·위탁·의뢰, 가게 강화, 도트 이미지와 한국어 픽셀 글꼴을 포함합니다.

144종 각각 진품·복제품 특징과 조사 부위를 작성했습니다. 제작·보존은 15가지 재질 규칙에 물품별 부위를 연결했습니다. 관찰은 텍스트 퍼즐이며 각 물품을 회전시키는 조작 미니게임은 아닙니다.

- 새로 시작: 기존 저장이 있으면 확인한 뒤 새 가게를 시작합니다.
- 불러오기: 같은 웹 주소·기기·브라우저의 저장을 이어갑니다.
- 체험 튜토리얼: 31단계를 직접 플레이합니다. 원하는 장면을 선택해 연습할 수 있고 실제 저장을 바꾸지 않습니다.
