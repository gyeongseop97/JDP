# 수상한 전당포 · Midnight Pawn

자정의 전당포에서 손님의 말, 물건의 흔적과 가격을 비교하는 모바일 싱글 플레이 게임입니다. 시간 제한은 없습니다.

## v4.2 모든 글자 도트 글꼴

대사·선택지·가격과 금고 숫자·가격 입력칸·보관함·수집록·가게 관리·설정·팝업·튜토리얼·작은 안내·마우스 설명을 모두 동봉된 Galmuri11 도트 글꼴로 통일했습니다. 수집록의 미발견 물음표도 같은 글꼴로 그립니다. 글꼴은 먼저 불러오며, 인위적으로 굵게 늘리지 않고 작은 문구의 크기와 줄 간격을 조정했습니다.

`typography.css`도 다른 파일과 함께 업로드하세요. 기존 저장과 거래 규칙은 그대로 유지됩니다.

## v4.1 대화 화면

- 등장인물 그림 아래의 도트 대화창에 현재 대사와 선택지를 함께 표시합니다.
- 대화창 오른쪽 위 **전체 대화**를 누르면 이번 손님과 나눈 대화·관찰 기록을 스크롤로 읽습니다. 닫으면 같은 거래로 돌아옵니다.
- 기존 별도 대화·선택지 영역은 제거했습니다. 현재 대사가 이미 보이면 선택 뒤에도 화면 위치를 유지합니다.
- 새로 생성한 `dialogue-frame.webp`를 대화창 테두리에, `title-logo.webp`를 시작 화면의 한글 제목 이미지에 사용합니다.
- 체험 튜토리얼 첫 단계에서도 전체 대화를 열고 닫는 방법을 직접 연습합니다.
- 이전 저장은 그대로 이어집니다. 이전 버전에서 이미 잘린 오래된 대화는 복구할 수 없지만, 이번 버전부터는 현재 방문의 대화에 32개 제한을 두지 않습니다.

## 시작하기

- **새로 시작**: 새 가게를 엽니다. 손님과 사건은 새로 섞입니다. 저장이 있으면 교체 전에 확인합니다.
- **불러오기**: 같은 기기·브라우저의 저장으로 돌아갑니다.
- **체험 튜토리얼**: 별도 연습 가게에서 대화, 조사, 가격 입력, 매입·판매, 관계, 보관함과 가게 관리를 직접 해 봅니다. 연습은 실제 저장을 바꾸지 않습니다. 중간에 나가거나 장을 골라 다시 연습할 수 있습니다.

## 거래의 흐름

1. 손님이 물건을 팔러 왔는지, 내 재고를 사러 왔는지 확인합니다.
2. 출처·재료·사연·급히 거래하려는 이유를 듣습니다. 어떤 정보를 얻을지 선택해야 하며 대화 기회는 한정됩니다.
3. 돋보기 또는 불빛과 조사할 부분을 직접 고릅니다. 조사는 두 번입니다. 첫 조사는 무료이며, 두 번째는 인내심 1을 소모하지만 친절한 손님이나 친밀도 40 이상인 손님은 면제됩니다. 게임은 손님의 힌트에 맞는 정답 도구나 위치를 표시하지 않습니다.
4. 말과 실제 관찰을 직접 비교합니다. 단서를 놓치거나 잘못된 곳을 조사하면 기회를 놓칠 수 있습니다. 정교한 가품이나 기억이 흐릿한 진품 주인도 있습니다.
5. 원하는 금액을 직접 적어 제안합니다. 수락, 역제안, 불쾌감과 퇴장을 보고 다음 행동을 결정하세요. 최종 **매입/판매 버튼**을 눌러야 돈과 물건이 오갑니다.
6. 보관한 물건은 구매 손님에게 직접 권할 수 있습니다. 취향에 맞는 물건과 설명을 고르고, 판매 가격도 직접 흥정합니다.

같은 이름의 물건이라도 매번 다른 개체입니다. 각각 진품/가품, 보존 상태와 등급이 다릅니다. 한번 진품을 발견했다고 다음 물건까지 진품이라는 보장은 없습니다.

## 손님과 관계

24명의 손님마다 좋아하는 품목, 싫어하는 품목, 성격, 지식, 인내심, 절약 성향과 말투가 다릅니다. 만족스러운 가격과 대화는 친밀도를 높이고, 무례한 흥정이나 근거 없는 단정은 관계를 해칩니다. 우호적인 손님은 협상을 더 너그럽게 받아들입니다.

손님은 가품인 줄 모르고 가져오기도 하고, 의도적으로 이야기를 꾸미기도 합니다. 물건이 진품인지와 손님이 정직한지는 별개의 문제입니다. 판매할 때도 모조품이라는 사실을 알릴지, 진품이라고 설득할지 선택할 수 있습니다. 상대가 무엇을 믿었는지에 따라 만족도가 달라집니다.

## 수집과 운영

- 12개 분류의 물건 144종, 9개 등급, 24명의 손님과 고유 상황 대사 768개
- 방문 순서, 물건과 하루 사건은 무작위이며 저장을 불러와 같은 거래를 재추첨할 수 없습니다.
- 구매 손님과 직접 흥정하거나, 도매처에 빠르게 판매하거나, 손님 2명 뒤 정산되는 위탁 판매를 선택합니다.
- 보관함, 물건·손님·등급 수집록, 감정·진열장·명성 강화, 업적과 거래 장부가 있습니다.
- 재고 없이 금고가 비었다면 하루 한 번 심부름으로 재기 자금을 마련할 수 있습니다.

## GitHub에 올리기

압축을 푼 **파일 전체**를 JDP 저장소 첫 화면에 업로드하고 Commit changes를 누르세요. 이번 배포본은 이미지와 글꼴도 모두 같은 폴더에 있습니다. 기존 게임 파일도 함께 교체해야 합니다.

이미 Pages가 켜져 있다면 설정을 다시 바꿀 필요가 없습니다. 처음이라면 **Settings → Pages → Deploy from a branch → main / (root) → Save**를 선택합니다.

게시 뒤 게임 주소: https://gyeongseop97.github.io/JDP/

자세한 절차는 [GITHUB-PAGES.md](GITHUB-PAGES.md)를 확인하세요. 별도 설치·빌드·API 키가 필요하지 않습니다.

## 저장

현재 기기·브라우저에 자동 저장하며 백업을 함께 보관합니다. 이전 버전의 금고·재고·수집록도 새 버전에서 이어받습니다. 다른 기기나 브라우저와 동기화하지 않습니다. 브라우저 데이터를 지우면 진행이 사라질 수 있습니다.

업데이트 후에는 같은 게임 주소를 새로고침하세요. 새 가게를 시작하거나 브라우저 데이터를 지울 필요가 없습니다. 휴대폰 홈 화면에 추가해 아이콘으로 실행할 수 있습니다. 오프라인 실행은 지원하지 않습니다.

## 로컬 미리 보기와 검증

Node.js가 있으면 `node preview.cjs --base /JDP/ --port 4176` 실행 후 http://127.0.0.1:4176/JDP/ 로 확인할 수 있습니다.

`node verify.cjs`는 거래·저장·관계·조사 기회·중복 처리 방지와 장기 혼합 거래를 검증합니다. 모바일 화면과 체험 튜토리얼은 별도 브라우저 검증으로 확인합니다.
